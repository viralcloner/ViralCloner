Profile Cache Cleaner

Chrome browser profiles can accumulate hundreds of megabytes of cached data (Cache, Code Cache, GPU Cache, etc.) over time. This tool removes those cache folders from all profile directories while keeping session data and cookies intact. It is safe to run at any time while no automations are running.
