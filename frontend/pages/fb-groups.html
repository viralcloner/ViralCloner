Groups Settings

Global scheduler settings for all workflows

comment

First Comment Delay

Random delay before posting the URL comment after a post

A random delay between min and max will be used. Set both to 0 to post immediately. Note: delay is skipped when viral monitoring uses the “Edit First Comment” action.

event_busy

Per-Profile Daily Posting Cap

Maximum posts any single Facebook profile can send per day

Set to 0 for no limit. Recommended: 8 or fewer to avoid restrictions.

shield

Posting Safety

Spread out activity so Facebook does not flag a profile for unusual behaviour

A random delay between min and max is enforced between ANY two posts from the same profile, across all groups and workflows. Set min to 0 to disable.

Makes each post look human: the profile loads the feed, scrolls, opens the real post box and types, instead of posting silently in the background. Safer against bot detection but slower. Can be overridden per workflow.

When on, Human-mode posts run in a visible browser so you can watch the warm-up, scrolling and composer typing. Turn this OFF for normal use — it shows a window for every post.

trending_up

Viral Monitoring

How long to watch a post and how often to re-check its metrics

pause_circle Viral monitoring is paused. Posts are not being checked.

At this interval, an idle account opens each group once and scrolls it like a human to read all monitored posts in a single pass — instead of checking each post separately. Longer intervals are safer.

radar

Automatic Group Scan

Refresh each group's name, cover and stats automatically

A group is scanned automatically the first time a profile is linked, then on this schedule. Requires at least one linked profile that is logged into Facebook.

science

Facebook Query IDs (Diagnostics)

Gather Facebook's GraphQL doc IDs to verify automations can talk to Facebook

This opens a linked profile in the background, browses Facebook, and tries to collect every query ID the automations rely on. Use it to confirm they are gathered successfully.

info CSV Format

The CSV must have 3 columns in this order, with a header row:

image_url Remote image URL (https://…). Downloaded automatically. Leave blank for no image.
post_text Post content. Required — rows without text are skipped. Wrap in quotes if it contains commas or line breaks.
url Article URL (https://…). Optional.
Example: 
image_url,post_text,url
https://example.com/img.jpg,"Check out this amazing burger recipe!",https://example.com/recipe
,"Great tips for social media growth",https://example.com/tips
https://cdn.example.com/photo.png,"Delicious vegan pasta",
